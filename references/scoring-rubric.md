# Scoring Rubric

## Dimensions (100 points total)

### 1. First Impression (15 pts)

| Score | Criteria |
|-------|----------|
| 15 | H1 title + one-line tagline + hero image/GIF/screenshot in first 10 lines |
| 10 | H1 + tagline, but no visual |
| 5 | H1 only, or tagline is vague ("A cool tool") |
| 0 | No clear title or description in first screen |

**Check:** Open the README. Without scrolling, do you know what this is?

### 2. Problem Statement (10 pts)

| Score | Criteria |
|-------|----------|
| 10 | Clear "Why" — explains what pain point this solves and for whom |
| 5 | Implied problem, but not stated explicitly |
| 0 | Jumps straight into features without context |

**Check:** Can a new visitor explain why they might need this?

### 3. Quick Start (20 pts)

| Score | Criteria |
|-------|----------|
| 20 | Install + first run in ≤3 copy-paste commands |
| 15 | Works but needs 4-6 steps |
| 10 | Works but needs configuration before first run |
| 5 | Partial instructions, user must figure out the rest |
| 0 | No install/setup section |

**Check:** Can someone go from `git clone` to working result in under 5 minutes?

### 4. Visual Demo (10 pts)

| Score | Criteria |
|-------|----------|
| 10 | GIF or video showing the tool in action |
| 7 | Screenshot(s) of key features |
| 3 | ASCII diagram or code snippet only |
| 0 | Text wall, no visuals |

### 5. Feature Clarity (10 pts)

| Score | Criteria |
|-------|----------|
| 10 | Feature list/table with short descriptions, scannable |
| 5 | Features mentioned but buried in prose |
| 0 | No feature section |

### 6. Usage / API Docs (10 pts)

| Score | Criteria |
|-------|----------|
| 10 | 2+ code examples covering main use cases, copy-paste ready |
| 7 | One example, covers basic usage |
| 3 | Inline code but no complete examples |
| 0 | No usage examples |

### 7. Badges & Metadata (5 pts)

| Score | Criteria |
|-------|----------|
| 5 | License + version + CI status badges |
| 3 | Some badges (e.g., license only) |
| 0 | No badges |

### 8. Community & Links (10 pts)

| Score | Criteria |
|-------|----------|
| 10 | Contributing guide + Issues link + Discussions/Chat + Author credit |
| 7 | Contributing guide + Issues link |
| 3 | Issues link only |
| 0 | No community section |

### 9. Pre-Publish Readiness (10 pts)

Checks that go beyond the README file itself:

| Score | Criteria |
|-------|----------|
| 10 | GitHub About description + 3+ topics + social preview + license file + release tagged |
| 7 | 3 of 5 items above |
| 3 | 1-2 items |
| 0 | None |

## Grade Bands

| Score | Grade | Action |
|-------|-------|--------|
| 90-100 | A | Ship it 🚀 |
| 80-89 | B | Minor polish needed |
| 70-79 | C | Needs improvement before launch |
| 50-69 | D | Major rewrite recommended |
| <50 | F | Start from template |
